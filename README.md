# Поиск старых log-файлов

Bash-скрипт для поиска и сортировки log-файлов по времени создания.

## Описание

Скрипт находит все файлы с расширением `.log` в текущей директории и её поддиректориях, сортирует их по времени создания и выводит 5 самых старых файлов.

## Использование

```bash
chmod +x find_old_logs.sh
./find_old_logs.sh
